# AI-Assisted Cargo Booking Experience
## UX/UI Design Assessment Case Study

---

# Project Overview

## Challenge

Design an AI-assisted workflow for the CargoWise Booking process that reduces operational effort, minimizes repetitive data entry, improves booking accuracy, and enhances the overall user experience for freight forwarders and cargo operators.

The proposed solution focuses on reimagining the booking workflow rather than simply adding AI features on top of the existing process.

---

# Problem Statement

The current CargoWise booking workflow requires users to manually create and manage multiple AWB (Air Waybill) shipments one at a time.

This results in:

- High operational effort
- Repetitive data entry
- Increased risk of manual errors
- Poor scalability for bulk bookings
- High cognitive load for operators

---

# Proposed Solution

## AI Booking Workspace

Instead of creating shipments one-by-one, users create a shipment batch.

AI assists with:

- Generating multiple AWBs
- Reusing shipment information
- Flight suggestions
- Validation checks
- Bulk editing

---

# Solution Workflow

```text
AI Booking Entry
        ↓
AI Generates AWBs
        ↓
Booking Workspace
        ↓

        ↓
Submission
        ↓
Success Dashboard
```
